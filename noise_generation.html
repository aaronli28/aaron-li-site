Quantifying Noise in Language Generation

Aaron Li · Ian Zhang
arXiv ↗ PDF ↓
How much does noise in the training data change what a language-generating algorithm can learn? We study this in the Kleinberg–Mullainathan generation-in-the-limit framework and prove two complementary results: a single noisy string is enough to strictly shrink the set of generatable collections — yet any finite amount of noise is no worse than just one.
Background

A game between an adversary and an algorithm

Kleinberg & Mullainathan (2024) introduced a clean model for studying language generation. There's a known collection 𝒞 of candidate languages over some universe ℤ. An adversary secretly chooses one language K ∈ 𝒞 and starts enumerating its elements. After each reveal, the algorithm must guess a new string — ideally one that's also in K.

Scroll down to watch a round play out.

01 — The setup

The model

Two players: an adversary who knows the target language K, and an algorithm trying to learn it. The adversary reveals strings one at a time; the algorithm has to guess unseen ones from K.

02 — Move 1

Adversary reveals x₀

The adversary outputs the first element of K. The algorithm sees x₀ and must respond.

03 — Move 2

Algorithm guesses z₀

Now it's the algorithm's turn. It outputs z₀, hoping z₀ ∈ K. Early guesses are usually wrong — that's fine. We only care about what happens eventually.

04 — Many rounds

The dance continues

Round after round: adversary reveals one more element of K, algorithm guesses one new string. The two interleave forever.

05 — Convergence

Generatable in the limit

If there exists a finite time t★ after which every algorithm guess is in K, we say 𝒞 is generatable in the limit. The algorithm never knows it's reached t★ — but from that moment on, it's producing valid strings from the target language.

06 — Noise

What if the data is dirty?

Real training data isn't pristine. We allow the adversary to insert up to i noisy strings — elements not in K. Here, x₂ is noise. The algorithm doesn't know which strings are real and which are junk, but it must still generate from K in the limit. Our paper asks: how much does noise actually cost?

Results

What we prove

Theorem 1 · Separation

One noisy string strictly hurts.

For both uniform and non-uniform generation, there exist collections that are generatable without noise but become impossible to generate as soon as the adversary can insert even a single string outside K. This answers an open question of Raman & Raman (2025) in the negative — noise is not a smooth degradation, it's a sharp cliff.

Theorem 2 · Collapse

One noisy string ≡ any finite amount.

Once you can tolerate one noisy string, you can tolerate any finite amount. Uniform generation with noise level 1 is equivalent to uniform generation at every finite noise level, and the same holds non-uniformly. This contrasts sharply with the strict hierarchy that does appear for generation in the limit (Bai, Panigrahi, & Zhang, 2026).

Theorem 3 · Characterization

A combinatorial criterion.

Building on the equivalence above, we give the first known characterization of non-uniform noise-dependent generatability in terms of an extension of the closure dimension.
